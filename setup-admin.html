Pyvanta — Temporary Admin Setup

Run this once. After creating the Firebase Authentication account, copy the UID and create its Firestore profile manually with role admin. Then delete this file from your deployed site.

This page contains temporary admin setup credentials. Do not leave it deployed.

Required Firestore profile



  1. Open Firebase Console → Firestore Database → users.
  2. Add a document whose document ID is the UID above.
  3. Add fields: uid (string), name (string), email (string), role (string = admin).
  4. Sign in with the admin email and password.
  5. Delete setup-admin.html from your deployed files.
